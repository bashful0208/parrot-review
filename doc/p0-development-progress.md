# P0 开发进度跟踪表

> 用途：本文件用于跟踪 P0 实际开发推进，不替代 `p0-delivery-checklist.md` 的范围定义。
> 原则：按业务依赖和交付先后排序；先打通闭环，再补增强能力；每项尽量细化到可直接开工或可明确验收。

## 当前阶段建议

- 当前主线：`Phase 0 基础底座` + `Phase 1 多租户与核心数据模型`
- 前置顺序：先稳定工程规范与 `Supabase` 平台底座，再推进组织隔离、核心主数据和接入链路
- 阻塞关系：未完成 `Supabase` 基础能力、组织隔离和核心主数据前，不进入完整 PR 自动审查闭环开发
- 开发节奏：优先完成“可运行链路”，再补低噪声、多语言、安全增强
